### 支持范围

售后服务仅对官方销售渠道购买的用户生效，覆盖未经修改的 Brandy Texture Link 2D 产品包、本 GitHub 所记录的工作流，以及文档中所说明的功能。

以下情况可能需要单独检测：

- 未列入测试清单的 Blender 或 Photoshop 版本；
- Beta、Nightly 或经过修改的宿主软件；
- 网络盘、NAS、虚拟文件系统、链接目录或延迟同步目录；
- 限制 Windows Script Host/cscript、COM 自动化或 Photoshop 脚本执行的工作站策略；
- 被修改的插件代码、生成项目文件或关联 PSD/PSB 结构；
- 第三方插件、自定义节点系统或工作室自动化引起的冲突。

对于以上情况，在收到您的邮件后，我会尽力排查。但因为运行环境的特殊性，我无法做出复现或解决以上情况的保证，请您谅解。
