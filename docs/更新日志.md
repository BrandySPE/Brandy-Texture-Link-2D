## Brandy Texture Link 2D v1.1.0

**Brandy Texture Link 2D** 原名为 **Brandy 2D Link**，更名后的第一个公开版本为 **1.1.0**。

本篇日志以插件更名后的版本为基准，仅记录内部测试版本 **1.0.0** 到公开发布版本 **1.1.0** 之间完成的更新概要。

### 从 Photoshop 文档创建项目

- 新增从 Photoshop 文档一次性创建项目的完整工作流，支持读取 PSD/PSB 中的图层与布局，将可用内容输出为独立透明贴图，并在 Blender 中自动创建项目集合、矩形面片、材质和图像数据。
- 自动生成可继续进行多贴图往返编辑的 Photoshop 工作文档及完整项目包。源文档仅用于首次导入，原文件不会被修改；后续编辑与同步均基于新建项目进行。
- 完整的 Brandy Texture Link 2D 工作文档会被识别为已有项目，避免被当作普通 Photoshop 文档重复导入。
- 新增透明像素边距、忽略隐藏图层、Alpha、Premultiply Alpha、导入缩放和面片 Z 轴间距等导入设置。
- 新增复杂图层检测，并提供“统一简化”“全部忽略”和“保留可用内容”三种处理方式。插件会尽可能保留图层名称、排列顺序、像素尺寸和画布位置，并对无法安全处理的内容给出明确结果。
- 完善 PSD 与 PSB 创建流程。默认创建 PSD；启用“使用 PSB”或超过 PSD 尺寸限制时使用 PSB，并对后台保存结果和实际文件格式进行验证。

### 项目创建、打开与切换

- 重构项目入口。插件会根据所选来源、项目路径和现有项目状态，自动判断应创建新项目还是打开已有项目；项目切换保留为独立操作，减少模式选择和误操作。
- “打开已有项目”现在可以从通过验证的项目包恢复 Blender 资源，并还原面片布局、导入缩放、水平轴方向、Z 轴间距、材质及贴图关联。
- 增强项目整体移动、关联记录异常和未完成项目的识别与恢复，避免将损坏或不完整的项目误当作可写入项目。
- 新增“使项目副本独立”。复制项目目录后，可为副本分配独立的项目与文档身份，并将 Photoshop 链接智能对象安全重连到副本贴图，避免副本继续写入原项目。
- 新增独立的项目副本事务恢复流程。插件会区分副本尚未修改、已经修改和无法确认的状态，减少不必要的回滚，同时在状态不明确时保留项目锁与恢复入口。
- 收紧“编辑单一贴图”和“为选中项恢复导入材质”的作用范围，只允许处理当前项目正式记录的资源，降低同名文件、共享网格或共享数据块被误修改的风险。

### Photoshop 往返编辑与任务恢复

- 完善“应用多图编辑”“撤销前一次应用”和中断写回恢复流程。写入前会建立必要备份，写入后执行严格校验；发生失败、中断或状态不一致时，可回滚或从保留记录继续恢复。
- 长时间 Photoshop 任务不再因超过前台等待时间而被直接视为状态不明。Blender 可以转为低频检查，Photoshop 继续执行任务。
- Photoshop 任务与其所属 Blender 文件会话现在会被持久识别。插件重载后可继续恢复任务；切换 Blender 文件时会隔离旧任务，防止结果被提交到错误文件。
- 只有用户明确执行“请求中断”时才会向 Photoshop 发送中断请求。重载插件或停止高频等待不会被误当作取消任务。
- 各项 Photoshop 操作会在执行前自行验证运行环境，不再要求用户先执行独立的 Photoshop 检测步骤。

### 自动刷新与性能

- 重构自动刷新系统，以项目集合为单位共享监控状态，避免同一项目在多个场景或视图中被重复扫描和重复刷新。
- 文件检查、项目结构更新和依赖关系处理改为分段执行，并加入延迟合并与受控重试，降低大型项目持续监控时的无效开销和界面卡顿。
- 手动刷新、项目切换、多图编辑和撤销操作会同步更新监控基线；关闭后重新启用自动刷新时，也不会忽略停用期间发生的贴图变化。
- 修复加载其他 Blender 文件、模块重载和多窗口环境下自动刷新处理器或运行时状态丢失的问题。

### 数据安全与稳定性

- 全面加强项目锁、任务状态、原子写入、文件指纹、哈希校验、写入前备份、失败回滚及异常退出恢复。
- 为未完成项目增加持久阶段记录和文件所有权清单。清理操作只处理能够确认由当前事务创建或接管的内容，避免删除未知文件或有效的 Photoshop 输出。
- 加强项目目录边界校验，拒绝通过符号链接、目录联接或外部路径绕过项目范围；同时限制外部 JSON 的文件大小、嵌套深度和数据复杂度。
- 新增 Windows 长路径预检，覆盖项目文件、贴图、任务记录、备份、临时文件及 Photoshop 动态输出路径，并统一给出可操作的错误提示。
- 完善 Photoshop 文档、项目说明、布局、贴图记录和 Blender 数据之间的交叉验证，防止项目身份、图层顺序、贴图路径或画布布局不一致时继续写入。
- 改进手动 JSX 模式、项目关联修复、任务记录目录和详细报告，使外部调用失败或自动监控中断时仍能保留可诊断、可恢复的信息。

### 界面与反馈

- 重新组织 Photoshop 工作流界面，将项目配置、任务状态和已连接项目的编辑操作集中到统一面板，并按实际项目状态显示可用入口。
- 分离 Photoshop 状态、任务状态、当前项目、切换目标、互通状态和安全状态，减少重复提示及底层技术信息对主要操作的干扰。
- 完善中文与英文界面覆盖，统一项目、图层、复杂内容处理、Premultiply Alpha、Photoshop 运行方式及任务检查等术语。
- 精简普通成功提示和常驻说明，将详细错误、路径及技术诊断集中到详细报告中，同时保留必要的恢复和处理建议。
