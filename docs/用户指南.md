## 使用建议

- 项目资产建议存放在本地磁盘，并预留足够空间保存 PSD、独立贴图和备份。
- 执行创建、切换、写回或恢复操作前，先保存相关文档，重要内容建议手动备份。
- 对于复杂结构的 PSD 文档，插件提供三种导入处理方式。但在导入前，建议进行备份并将图层进行简化或栅格化，能够有效缩短导入时长，并且让导入后的效果更可控。
- PSB 文档可作为兼容项执行各类导入与导出，但体积较大或过于复杂的文档可能操作失败，建议操作前先进行精简或手动转为 PSD 文档。
- 操作失败时，优先查看 **设置与报告** 中的 **打开详细报告**，按照报告中的提示进行排查，不要盲目修改项目 JSON 或重新连接智能对象。
- 请勿手动清理 `jobs`、`backups` 或其他内部项目文件夹，同时应避免多版本的 Blender 或 Photoshop 同时写入同一项目。

## 从 Blender 到 Photoshop

### 1. 打开 Photoshop

打开插件面板，在 **Photoshop 路径** 中选择 Photoshop 安装路径里的 Photoshop.exe，执行 **打开 Photoshop**。

### 2. 选择 Blender 集合

保持 **贴图来源** 为 **Blender 集合**，将所有您需要编辑的平面矩形 Mesh 对象（后文简称为 `2D 面片`）放入一个 Blender 集合，并在 **项目集合** 中选择该集合。

从 Blender 集合创建项目时，有效的 2D 面片应当：是平面矩形面片、名称唯一、具有有效的活动 UV 层、能识别唯一主贴图。

如果您的贴图已被打包进 `.blend` 中，请在创建前解压，并尽可能存放于本地磁盘。

材质可以包含其他节点或辅助贴图，但插件必须能够识别用于关联的唯一主贴图。存在多张候选贴图且无法判断主要贴图时，项目创建会停止并在执行报告中列出原因。

Blender 自动产生的 `.001`、`.002` 等数字后缀不会作为有效的贴图项名称区分。例如 `Arm` 与 `Arm.001` 可能被识别为重复名称，建议在创建项目前使用有实际含义的唯一名称。

对象上的约束、驱动和动画不会进入 Photoshop。项目记录的是创建项目时的基础静态构图。

### 3. 创建项目

在 **项目包路径** 中选择一个本地空文件夹，点击 **创建项目**。

**子集合**：启用后，项目会包含所选集合下的子集合对象。

**工作画布边距**：在整体贴图边界之外增加透明区域，用于为 Photoshop 中的整体绘制预留可见空间。该设置只扩展工作 PSD 文档的整体画布，不改变贴图之间的相对位置，也不会增加每张独立贴图的尺寸。

**使用 PSB**：未启用时默认创建 PSD 文档；当画布超过 30000 像素时，插件会自动改为创建 PSB 文档。

### 4. 完成关联

插件会复制集合中所有 2D 面片的贴图，粘贴到项目包中，并创建一个新的 PSD 文档，在 Photoshop 中复原 Blender 里的面片排列状态。您创建项目前的源贴图不会受到修改。

项目集合、贴图名称、贴图尺寸和整体布局会成为当前项目的关联基准，修改相关内容可能影响项目识别与关联。请在创建项目前完成相关修改，或在完成相关修改后重新创建项目。

### 5. 三个图层组

在 PSD 文档中，您可以看到 **BTL2 关联图层**、**BTL2 待合并图层**、**BTL2 已合并图层** 三个图层组，请不要进行移动、替换或重命名等手动修改，也不要在三个图层组内创建子图层组，确保文档结构为默认状态。

**BTL2 关联图层**：该组存放着与项目贴图对应的链接智能对象，用于复原 Blender 构图并完成坐标映射。

**BTL2 待合并图层**：该组用于放置执行 **应用多图编辑** 时所需的新增图层。图层组不透明度需要保持为 100%，混合模式保持 `正常` 或 `穿透`。

**BTL2 已合并图层**：执行过 **应用多图编辑** 的图层会被自动移入该组。该组仅为工作内容归档区，不能替代项目备份。

## 导入 PSD 文档

### 1. 选择 PSD 文档

正常完成前文提到的插件安装，并打开 Photoshop。在插件面板中，将 **贴图来源** 切换至 **Photoshop 文档**，并在 **PSD 文档** 中选择您要导入的 PSD 文档。

该功能会以当前图层状态创建项目，应视为一次性导入，而非对原始 PSD 的持续同步。

### 2. 导入设置

在 **项目包路径** 中选择一个本地空文件夹，并在下方的导入参数中设置 **透明像素边距**、**使用 Alpha** 等内容，之后点击 **创建项目**。

**透明像素边距**：在对每个图层裁切时，插件会按照该设置中的数值，对图层四周分别增加透明像素，以扩展预留画布空间，便于后续修改或进行色彩溢出。该设置不会改变图层在整体构图中的位置，但会增加贴图实际尺寸和占用空间。

**忽略隐藏图层**：启用后，隐藏图层以及位于隐藏父组中的内容不会导入。

**使用 Alpha**：启用后，插件会将贴图的 Alpha 输出连接到材质透明度，并为材质启用透明显示；关闭后，Alpha 通道不会参与材质显示，面片按不透明材质处理。该选项不会删除或修改贴图文件中的 Alpha 通道。

**预乘 Alpha**：启用后，贴图会按预乘 Alpha 进行读取。普通 PNG 等直通 Alpha 贴图通常保持关闭；只有贴图本身已经使用预乘 Alpha 时才应启用，否则透明边缘可能出现颜色或明暗异常。

**导入缩放**：控制 Photoshop 像素坐标转换为 Blender 单位的整体比例，不会缩放、重采样或修改贴图本身的像素尺寸。

**面片 Z 轴间距**：在相邻面片之间增加固定的 Z 轴距离，用于解决面片完全重叠时的闪烁和排序错乱。

### 3. 导入逻辑

PSD 文档导入时，插件会为每个成功导入的图层或资产创建一张 2D 面片，并将图层内容作为贴图接入材质。

处理复杂结构的 PSD 时，请尽可能将其转为精简的 PSD 文档。如果您的文档中存在大量智能对象链接、图层样式等内容，插件会提供 **统一简化**、**全部忽略**、**保留可用内容** 三种处理方式，但复杂效果导入后仍可能有损。

**统一简化**：普通图层直接导入，同时将复杂图层或图层组尽可能合并为单张图像，无法安全处理的内容会直接跳过。

**全部忽略**：普通图层直接导入，忽略复杂图层和图层组。复杂图层组中可独立处理的普通子图层仍可导入。

**保留可用内容**：普通图层直接导入，之后优先执行 **统一简化**，对于无法安全处理的内容，插件会读取图层中的有效信息，并使用透明占位保留位置和名称。

复杂内容导入后保留的是当前可见结果和布局，不会完整保留文字、蒙版、调整层、图层样式、剪贴关系或智能对象内部结构的可编辑性。

您还可以通过给名称添加前缀来控制导入：

`[ignore]`：添加在图层或图层组名称前，插件会跳过对应内容。

`[asset]`：添加在图层组名称前，插件会将该组作为一个整体资产进行处理。

### 4. 完成导入

成功导入并创建项目后，所有 2D 面片会位于 Blender 集合中，您可点击 **打开已有项目** 正常进行项目操作，在 Photoshop 中完成编辑贴图与自动刷新。

从 PSD 文档导入生成的项目贴图以 PNG 格式进行保存。

## 项目包须知

项目包是 Blender 与 Photoshop 之间持续关联所使用的正式资产目录，并非临时缓存。

项目成功创建后，Blender 会重新读取项目包中的贴图副本，后续编辑和多图写回修改的也是这些副本，创建项目前的外部源贴图不会受到影响。

不要单独移动、改名或替换其中的 PSD、贴图、JSON 文件和内部目录。如果您需要移动项目，请整体移动项目包。

如果您希望复制项目，并将新的项目副本作为独立项目继续编辑，请通过插件选择副本项目，并使用插件出现的 **使项目副本独立** 完成独立化，之后再继续操作。

`textures` 文件夹：当前项目实际使用和修改的独立贴图。

`photoshop` 文件夹：插件创建的工作 PSD 文档。

`layout` 文件夹：贴图布局与关联信息。

`jobs` 文件夹：Blender 与 Photoshop 之间的任务记录。

`backups` 文件夹：写回、撤销和异常恢复所需的备份。

`source` 文件夹：从 PSD 文档创建项目时保存的源文档副本。

`brandy_texture_link_2d_project.json` 文件：项目包入口。

## 单图编辑与整体绘制

### 单图编辑

当您需要编辑单一贴图时，可直接在插件创建的 PSD 文档中打开智能对象并编辑；或者直接在 Blender 中选中某个 2D 面片，点击插件的 **编辑单一贴图**，即可打开对应的贴图文件进行编辑。

在 `单图编辑` 模式中，您的编辑和保存对象需要是 `智能对象` 或 `单一贴图文件`，而非总 PSD 文档。

编辑过程中，项目贴图应继续保持原文件路径和像素尺寸，否则可能导致刷新失败。

### 整体绘制

1. 绘制并重命名

当您需要进行整体绘制时，例如：绘制一条横跨 `Leg_Thigh` 、`Leg_Shin` 、`Leg_Foot` 三张贴图的花纹。

您可直接在总 PSD 文档中新建一个图层进行绘制，之后对该图层执行两次 `复制并创建新图层（Ctrl+J）` 操作，可以得到三个相同内容的图层。

将三个图层分别重命名为 `Leg_Thigh`、`Leg_Shin`、`Leg_Foot`，并全部放入 **BTL2 待合并图层** 图层组中，之后对总 PSD 文档执行保存。

您可一次性对更多图层执行此类操作。

2. 应用多图编辑

点击插件的 **应用多图编辑**，您的绘制内容会被分别应用到三张贴图中，超过对应贴图画布大小的像素会被裁切。

名称不匹配的图层不会参与应用。

运行应用任务期间，请勿同时在 Photoshop 或其他程序中修改项目文件。

3. 撤销前一次应用

如果您不满意此次修改，可点击新弹出的 **撤销前一次应用** 进行安全撤销。

**撤销前一次应用** 只针对 **应用多图编辑** 生效，不是通用历史记录，并且只用于恢复最近一次应用所修改的 PSD 文档、关联信息和项目贴图。

在 **应用多图编辑** 之后，相关 PSD 文档与贴图不能进行任何实际操作，否则插件会拒绝撤销。

## 其他细节

### 自动刷新与手动刷新

当 **自动刷新** 处于激活状态时（按键亮起），您在 Photoshop 中的 `保存（Ctrl+S）` 操作可自动触发 Blender 中的刷新显示。自动刷新并非实时同步，可能存在 3 秒左右延迟，受项目大小及硬件情况影响。

自动刷新会定期检查项目贴图文件。当文件已经完成写入且像素尺寸没有变化时，Blender 会重新载入图像。

您也可以关闭 **自动刷新**，在编辑并保存后，通过 **刷新贴图** 进行手动刷新。

如果贴图像素尺寸发生变化，插件不会自动调整 Blender 面片，而会停止或跳过该贴图的刷新。需要改变贴图尺寸时，建议重新建立项目。

### 项目入口

如果您的 **项目包路径** 中包含插件创建过的项目，**创建项目** 会自动切换为 **打开已有项目**。

当您已经打开某个项目时，切换 **项目包路径**，如果路径为空文件夹，**打开已有项目** 会自动切换为 **创建项目**；如果路径中包含插件创建过的项目，在 **创建项目/打开已有项目** 下方会弹出 **切换项目**。

切换过程中，原项目会继续保持有效；只有候选项目完成验证后，才会替换当前项目。切换失败不会主动提交不完整的候选项目。

### 设置与报告

在日常使用中如果遇到问题，**打开详细报告** 中可找到任务失败的原因、部分任务的执行细节，以及报错后的解决办法。

**高频检查时长（秒）** 正常保持默认即可。超过设定时长后，Photoshop 会继续运行，Blender 也会继续等待和检查结果，只是降低检查频率以减少持续轮询。该设置不是任务超时设定，也不会终止 Photoshop。

当您的自动关联失效时，可尝试将 **Photoshop 运行方式** 从 **Windows COM** 切换为 **手动脚本**。在 **手动脚本** 模式下，您的操作会生成对应的脚本文件，之后您可在 Photoshop 中通过 `文件` > `脚本` >`浏览` 中，手动运行任务目录里的 `run_brandy_texture_link_2d_job.jsx`。该模式只限于临时应急或特殊需要，不建议作为日常使用。

插件支持中英双语，您可通过 **插件界面语言** 修改默认语言，修改后需要重启插件或 Blender 刷新面板。

### 安全性与恢复

插件中还存在以下隐藏按键，它们分别用于处理不同情况下的安全性任务，只有在特定情况下才会弹出，您可根据提示进行操作。

**打开任务记录目录**：查看手动脚本、任务 JSON、结果及诊断文件。

**查看检测摘要**：确认 PSD 文档的普通和复杂内容数量。

**查看完整检测结果**：查看每个图层的处理决定和原因。

**恢复中断贴图更新**：从可信备份恢复被中断的贴图写回。

**恢复未完成项目**：继续提交已创建工作文档但尚未绑定的项目。

**恢复项目副本事务**：处理被中断的副本独立化。

**清除失效项目锁**：仅在确认写入已经停止后释放异常锁。

**确认任务已结束**：只清理 Blender 的任务等待状态，不会终止 Photoshop。

## 附加功能

### 切换贴图格式

该功能会在同一贴图目录中，查找并切换到已经存在的同名 PNG、TGA、JPG 或 JPEG 文件，用于批量切换贴图。

该功能不会转换图像文件格式。共享图像、未保存图像和打包图像不会被修改。

### 便捷功能

**复制着色器参数到选中项**：复制最后一个选中的着色器参数，粘贴到其他选中项的着色器参数中。仅支持复制未连接且名称一致的输入值。

**为选中项的材质查重与合并**：安全处理插件生成且尚未修改的重复材质。

**为选中项恢复导入材质**：根据导入记录恢复导入时的材质和贴图关联。

**独显选中项**：在当前 3D 视图中临时独立显示选中项，在独显期间可正常进行移动、编辑等操作，再次点击按键可恢复点击前的显示状态。

### PhotoshopToSpine 静态 JSON

该功能只作为有限支持，并非 PhotoshopToSpine 插件的替代项。

该功能可以导入由 PhotoshopToSpine 导出的静态碎图与 JSON。导出功能不会导出贴图，只会将当前 Blender 构图的位置信息记录在兼容 JSON 中并导出。

非常感谢 PhotoshopToSpine 插件的作者 EsotericSoftware，您的插件帮助我在早期的 2D 角色制作中节省了大量时间。

### Spine2D Region Attachment 导入

该功能只作为有限支持，不支持与 Spine 2D 软件本身进行关联。

该功能只能用于导入 Spine JSON 中的静态 Region Attachment，并按照 Setup Pose 创建矩形面片；不支持导入 Spine 动画、Mesh Attachment、约束系统或可动画的 Blender 骨架。
