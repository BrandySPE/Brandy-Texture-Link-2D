## 使用建议

- 项目包与项目相关资产建议存放至本地磁盘，否则可能产生额外的延迟或其他不稳定情况。
- PSB 文档可作为兼容项执行各类导入与导出，但体积较大或过于复杂的 PSB 文档可能操作失败，建议操作前先进行精简或手动转为 PSD 文档。
- 在部分功能的等待时间内，可按键盘上的 `ESC` 键停止任务，但停止前已开始执行的任务不会立即停止。例如，当使用插件打开 Photoshop 时按 `ESC` 键，Photoshop 可能仍会完成打开任务，但不会执行后续任务。
- 操作失败时，请优先查看**设置与报告**分栏中的**打开详细报告**，按照报告中的提示进行排查，不要盲目修改项目 JSON 或手动重连智能对象。
- 请勿在插件执行任务期间，手动修改、删除项目包中的文件。除非您明确清楚您在做什么，否则请不要手动操作项目包，避免文件变更导致项目识别失败或项目包作废。
- 移动、切换项目包时，建议使用插件的**使项目副本独立**和**切换项目**功能，详情请阅读关联核心章节。

## 安装

在 Blender 中打开`编辑 > 偏好设置 > 获取扩展 > 右上角菜单的从磁盘安装`，选择完整的 Brandy Texture Link 2D.zip 插件包。请不要解压 ZIP 文件。

确保您在`偏好设置 > 插件`中启用了 Brandy Texture Link 2D。

回到 3D 视图中按 `N` 键打开侧边栏，之后展开 **Brandy** 标签，在 **Photoshop 路径**中选择 Photoshop 安装路径里的 `Photoshop.exe`。

## 从 Blender 集合建立关联

当安装了多个版本的 Photoshop 时，插件会仅调用 **Photoshop 路径**中配置的版本。如果版本问题造成了任务中断，请在关闭其他版本的 Photoshop 后重试，或按具体提示内容进行操作。

请避免多版本的 Blender 和 Photoshop 同时写入同一项目。

### 1. 确认贴图来源

在**项目包路径**中选择一个本地空文件夹，保持**贴图来源**为**Blender 集合**。

### 2. 选择 Blender 集合

将您需要编辑的所有平面矩形 Mesh 对象（后文简称为 2D 面片）放入一个 Blender 集合，并在**项目集合**中选择该集合，之后点击**创建项目**。

一张有效的 2D 面片至少应当满足：是平面矩形面片、名称唯一、具有有效的活动 UV 层、能识别唯一主贴图。

如果您的贴图已被打包进 `.blend` 中，请在创建前解压，并尽可能存放于本地磁盘。

Blender 中的 2D 面片允许携带约束、骨骼、动画等内容，但只有创建项目时的基础静态构图会进入 Photoshop。

2D 面片的材质可以包含其他节点或辅助贴图，但必须存在唯一主贴图。当存在多张候选贴图且无法判断主要贴图时，插件会停止创建项目，并在详细报告中列出原因。

Blender 自动产生的 `.001`、`.002` 类数字后缀，不会作为有效的贴图名称区分。例如，`Arm` 与 `Arm.001` 可能被识别为重复名称，建议在创建项目前使用唯一名称。

功能注释：

- `子集合`：启用后，项目会包含所选集合下的子集合对象。
- `工作画布边距`：在整体贴图边界之外增加透明区域，用于为 Photoshop 中的整体绘制预留可见空间。该设置只扩展工作 PSD 文档的整体画布，不改变贴图之间的相对位置，也不会增加每张独立贴图的尺寸。
- `使用 PSB`：未启用时，插件默认创建 PSD 文档。当画布超过 30000 像素时，插件也会自动改为创建 PSB 文档。

### 3. 创建项目

插件会复制该集合中所有 2D 面片的源贴图，粘贴到项目包中，并创建一个新的 PSD 文档，在 Photoshop 中复原 Blender 里的贴图排列。您创建项目前的源贴图不会被修改。

插件会在这一步记录每张贴图的名称、尺寸、布局和 Alpha 等信息，作为项目关联的基准，也为后续的合并与分配操作提供可靠信息。

插件对信息变动的情况具有一定的防御机制。例如，在 PSD 文档中临时修改了贴图的名称、尺寸、布局后，插件可能会暂时拒绝执行任务，但只要将相关信息恢复正确后重试，插件通常能够继续执行任务。

修改 PSD 文档的图层顺序不会影响插件执行任务，但也不会变更贴图的遮挡顺序。

在 Blender 中可变更 2D 面片的名称和位置，但这些变更信息不会同步到 PSD 文档中。

以下几项内容一旦进行修改或删除，可能对项目造成严重损坏：

- Blender UID；
- 手动修改项目结构、文件或链接；
- **BTL2 关联图层**、**BTL2 待合并图层**、**BTL2 已合并图层**三个图层组可以临时重命名，但如果它们被删除，即便新建三个同名图层组，插件也无法继续正常工作。

## 从 PSD 文档建立关联

### 1. 确认贴图来源

在**项目包路径**中选择一个本地空文件夹，将**贴图来源**切换至 **Photoshop 文档**。

### 2. 选择 PSD 文档

在 **PSD 文档**中选择您要导入的 PSD 文档，在下方的导入参数中设置**透明像素边距**、**使用 Alpha**、**面片 Z 轴间距**等选项，之后点击**创建项目**。

处理复杂结构的 PSD 文档时，请尽可能将其转为精简的 PSD 文档。如果您的文档中存在大量智能对象链接、图层样式等内容，插件会提供**统一简化**、**全部忽略**、**保留可用内容**三种处理方式，但复杂效果导入后仍可能产生差异。

功能注释：

- `统一简化`：普通图层直接导入，同时将复杂图层或图层组尽可能合并为单张图像，无法安全处理的内容会直接跳过。
- `全部忽略`：普通图层直接导入，忽略复杂图层和图层组。复杂图层组中可独立处理的普通子图层仍可导入。
- `保留可用内容`：普通图层直接导入，复杂图层或图层组优先整体简化；复杂组无法安全整体处理时，会继续展开并导入其中可用的子图层，其余无法处理的内容使用透明占位保留位置和名称。

您还可以通过给名称添加前缀来控制导入：

- `[ignore]` 前缀：添加在图层或图层组名称前，插件会跳过对应内容。
- `[asset]` 前缀：添加在图层组名称前，插件会将该组作为一个整体资产进行处理。

复杂内容导入后保留的是当前可见结果和布局，不会完整保留文字、蒙版、调整层、图层样式、剪贴关系或智能对象内部结构的可编辑性。

PSB 文档作为兼容项导入格式，但体积较大或过于复杂的文档可能无法完整导入。

功能注释：

- `透明像素边距`：在对每个图层裁切时，插件会按照该设置中的数值，对图层四周分别增加透明像素，以扩展预留画布空间，便于后续修改或进行色彩溢出。该设置不会改变图层在整体构图中的位置，但会增加贴图实际尺寸和占用空间。
- `忽略隐藏图层`：启用后，隐藏图层以及位于隐藏父组中的内容不会导入。
- `使用 Alpha`：启用后，插件会将贴图的 Alpha 输出连接到材质透明度，并为材质启用透明显示；关闭后，Alpha 通道不会参与材质显示，面片按不透明材质处理。该选项不会删除或修改贴图文件中的 Alpha 通道。
- `预乘 Alpha`：启用后，贴图会按预乘 Alpha 进行读取。普通 PNG 等直通 Alpha 贴图通常保持关闭；只有贴图本身已经使用预乘 Alpha 时才应启用，否则透明边缘可能出现颜色或明暗异常。
- `导入缩放`：控制 Photoshop 像素坐标转换为 Blender 单位的整体比例，不会缩放、重采样或修改贴图本身的像素尺寸。
- `面片 Z 轴间距`：在相邻面片之间增加固定的 Z 轴距离，用于解决面片完全重叠时的闪烁和排序错乱。

### 3. 创建项目

插件会在 Blender 中，为每个成功导入的图层或资产创建一张 2D 面片，并将图层内容作为贴图接入材质。插件会按照 PSD 文档中的图层排列，处理 2D 面片之间的前后遮挡顺序。

该导入可视为一次性导入，您的后续操作将不再和源 PSD 文档关联，源 PSD 文档也不会被修改。完成导入后，插件会按从 Blender 集合建立关联的逻辑，最终完成新 PSD 文档的创建与关联。

从 PSD 文档导入生成的项目贴图将以 PNG 格式进行保存。

## 关联核心

### 1. 项目包

无论您使用哪一种方式建立关联，当**项目包**创建完成之后，您的 Photoshop 都会被启动。

项目包存放于您选择的**项目包路径**中，是 Blender 与 Photoshop 之间持续关联所使用的正式资产目录。

如果在**项目包路径**中选择一个插件创建过的项目包，**创建项目**会自动切换为**打开已有项目**。

当已经打开某个项目时，重新在**项目包路径**中选择一个插件创建过的项目包，在**打开已有项目**下方会显示**切换项目**按键，可使用该按键在多个项目包之间快速切换。

切换过程中，原项目会继续保持有效；只有候选项目完成验证后，才会替换当前项目。切换失败不会主动提交不完整的候选项目。

如果您复制了一份当前项目包的完整副本到新路径，那么可以在**项目包路径**中选择该副本，插件会显示**使项目副本独立**按键。点击后，插件会将该副本重新记录为一个新的独立项目包。

完整项目包中通常包含以下文件夹：

- `textures` 文件夹：当前项目实际使用和修改的独立贴图。
- `photoshop` 文件夹：插件创建的工作 PSD 文档。
- `layout` 文件夹：贴图布局与关联信息。
- `jobs` 文件夹：Blender 与 Photoshop 之间的任务记录。
- `backups` 文件夹：写回、撤销和异常恢复所需的备份。
- `source` 文件夹：从 PSD 文档创建项目时保存的源文档副本。

### 2. 三个图层组

此时打开的 PSD 文档中，会存在 **BTL2 关联图层**、**BTL2 待合并图层**、**BTL2 已合并图层**三个图层组。

请勿删除这三个图层组：

- `BTL2 关联图层`：存放着所有与 2D 面片名称对应的智能对象，它们的对应贴图、排列关系和 Alpha 信息都会在创建项目时被记录。
- `BTL2 待合并图层`：该组用于放置执行**应用待合并图层**和**分配待合并图层**时所需的新图层。图层组不透明度需要保持为 100%，混合模式保持正常或穿透。
- `BTL2 已合并图层`：执行过**应用待合并图层**和**分配待合并图层**的图层会被自动移入该组，用于执行撤销任务。该组仅为工作内容归档区，不能替代项目备份。

## 单图编辑模式

创建项目完成后，下方会显示核心的操作界面。

您可直接在 Blender 中选中某个 2D 面片，点击插件的**编辑单一贴图**，即可打开对应的贴图文件进行编辑。

当**自动刷新**处于激活状态时（按键亮起），您在 Photoshop 中的保存 `Ctrl+S` 操作会自动触发 Blender 中的刷新显示。自动刷新机制并非实时同步，在保存操作后可能存在数秒延迟，延迟受项目大小及硬件情况影响。

在单图编辑模式中，您需要执行编辑和保存的对象为单一贴图文件或总 PSD 文档中的单一智能对象图层，仅对总 PSD 文档进行保存无法触发自动刷新。

使用**编辑单一贴图**进行编辑并保存后，在创建项目时被记录的 Alpha 信息变更为编辑后的 Alpha。这能够为擦除已有像素后的贴图提供可靠的 Alpha 信息，并直接影响后续的**允许写入透明区域**和**允许分配至透明区域**。

您也可以关闭**自动刷新**，通过点击**刷新贴图**进行手动刷新。

**编辑单一贴图**可以修改贴图内容和 Alpha 信息，但不要改变该贴图文件的像素宽高；裁剪、画布大小或图像大小等操作如果改变正式贴图尺寸，会导致项目尺寸校验失败。

在总 PSD 文档中双击进入智能对象也可进行贴图编辑，并用保存触发自动刷新，但这种修改方式不会变更创建项目时被记录的 Alpha 信息。

您可根据对 Alpha 信息的编辑需求，选择对应的编辑方式。

## 多图编辑模式

该模式以**应用待合并图层**与**分配待合并图层**两个按键为核心，满足常见重绘管线中的各类需求。

这部分内容书面描述较为繁琐，建议配合 [YouTube 演示教程](https://www.youtube.com/watch?v=Hcl-jo4UIig) 进行查看。

### 1. 应用待合并图层

例如：需要对 Leg_Thigh、Leg_Shin、Leg_Foot 三张贴图进行绘制。

此时可在总 PSD 文档中新建三个图层进行绘制，之后将三个新图层分别改名为 Leg_Thigh、Leg_Shin、Leg_Foot，一起放入 **BTL2 待合并图层**图层组中，并对总 PSD 文档进行保存。

点击**应用待合并图层**，插件会自动将三个新图层按名称合并至对应的 Leg_Thigh、Leg_Shin、Leg_Foot 三张贴图中，并自动刷新显示。

此处仅以三张贴图举例，更多图层均可按此逻辑进行操作。

被隐藏的图层会保留在原处，不参与合并。

这是多图编辑模式中最简单、可控的编辑方式。

在未勾选**允许写入透明区域**时，插件会按当前记录的 Alpha 信息，自动裁切掉进入透明区域内的新增像素，确保原有像素边缘不会被扩展。

在勾选**允许写入透明区域**时，插件则允许新增像素写入透明区域，只会自动裁切掉超出原有画布大小的内容。

### 2. 分配待合并图层

该按键的使用方式与**应用待合并图层**类似，是否勾选**允许分配至透明区域**的影响也与**允许写入透明区域**类似，相似内容不再赘述。

区别在于**分配待合并图层**会按照项目记录的贴图遮挡顺序，对多个图层的重叠区域进行自动分配，确保在上层的贴图获得新增像素后，被遮挡的下层贴图不会获得相同像素。

例如：需要绘制一条横跨 Leg_Thigh、Leg_Shin、Leg_Foot 三张贴图的花纹，但三张贴图的关节部位均存在遮挡，而您不希望新增像素落入被遮挡的区域。

此时可新建一个图层绘制完整花纹，完成后对该图层执行两次复制并创建新图层 `Ctrl+J` 操作，得到三个相同内容的图层。将三个新图层分别改名为 Leg_Thigh、Leg_Shin、Leg_Foot，一起放入 **BTL2 待合并图层**图层组中，并对总 PSD 文档进行保存。

点击**分配待合并图层**后，大腿与膝盖处的花纹会被分配至位于上层的 Leg_Thigh 贴图，而下层的 Leg_Shin 贴图不会再次获得膝盖处的花纹，只会获得未被遮挡的小腿处的花纹。

最终，整条花纹会被完整分配至 Leg_Thigh、Leg_Shin、Leg_Foot 三张贴图，不会产生断层，也不会因新增像素叠加而产生不可控的视觉变化，这对于半透明像素的处理尤为重要。

### 3. 对单图层分配

该选项仅对**分配待合并图层**生效，效果类似智能分配。

勾选后，仅需在 **BTL2 待合并图层**中放入一个新图层，插件会将检测到的所有新增像素，按照**分配待合并图层**的逻辑，自动分配至下方所有被覆盖的贴图中。

如果放入多个图层，插件会先对 **BTL2 待合并图层**中的所有新图层进行合并，再执行分配。

该选项很便捷，但耗时较长，建议小范围使用。

### 4. 撤销上次应用 / 撤销上次分配

在每次执行完**应用待合并图层**或**分配待合并图层**后，插件会在两个按键下方分别显示**撤销上次应用**或**撤销上次分配**。

点击撤销后，插件会复原上次操作影响的贴图，并将被应用或分配的新图层放回 **BTL2 待合并图层**中。

该撤销仅对前一次的操作生效，且应用和分配操作共享同一次撤销机会，即在执行**应用待合并图层**后再执行**分配待合并图层**，上一次的**应用待合并图层**便不再支持撤销。

未生效的操作，如对空图层执行的应用和分配，不会消耗该撤销机会。

对于执行过**使项目副本独立**的项目，未使用的撤销机会被清空。

## 其他设计

### 设置与报告

在日常使用中如果遇到问题，**打开详细报告**中可找到任务失败的原因、部分任务的执行细节，以及报错后的解决办法。

当 Photoshop 自动调用无法正常工作时，可尝试将 **Photoshop 运行方式**从 **Windows COM** 切换为**手动脚本**。在**手动脚本**模式下，您的操作会生成对应的脚本文件，之后您可在 Photoshop 中通过 `文件 > 脚本 > 浏览` 中，手动运行任务目录里的 `run_brandy_texture_link_2d_job.jsx`。该模式只限于临时应急或特殊需要，不建议作为日常使用。

插件支持中英双语，您可通过**插件界面语言**修改默认语言，修改后需要重新加载插件或重新启动 Blender。

如果您有疑问或者需要反馈，可查看`技术支持`文档或联系：`brandyspe2026@gmail.com`，我看到邮件后会尽快回复。

### 安全性与恢复

插件中还存在部分隐藏按键，它们分别用于处理不同情况下的安全性任务，只有在特定情况下才会显示。

您可根据提示使用以下按键：

- `打开任务记录目录`：查看当前手动任务或异常任务的脚本、JSON、结果与诊断记录。
- `查看检测摘要`：查看 PSD/PSB 文档的图层分类数量与代表性处理结果。
- `查看完整检测结果`：查看每个图层的处理决定和原因。
- `恢复中断贴图更新`：从可信备份恢复被中断的多图编辑贴图写回。
- `恢复未完成项目`：继续提交已创建工作文档但尚未绑定的项目。
- `修复项目关联`：在项目关联编号不一致时备份并修复关联记录，以便重新打开或切换项目。
- `恢复项目副本事务`：恢复或完成被中断的项目副本独立化任务。
- `清除失效项目锁`：仅在确认写入已经停止后，释放异常项目锁并清理对应遗留任务状态。如果存在未完成的项目副本独立化任务，插件不会允许单独清锁，而是强制先执行 `恢复项目副本事务`。
- `确认任务已结束`：确认 Photoshop 任务已经结束后，释放项目锁、保留可恢复文件并清除任务状态；不会终止 Photoshop。
- `请求中断`：任务运行时出现。向 Photoshop 写入 cancel.request，Photoshop 会在安全检查点停止；不是强制结束进程，也不会关闭 Photoshop。
- `继续恢复任务`：Blender 与原 Photoshop 任务失去正常监控关系后出现。它首先只读监控原任务，确认完整结果后才接管锁并提交。
- `转为低频检查`：把结果监控降为低频后台检查，不会停止 Photoshop。

## 附加功能

### 切换贴图格式

该功能会在同一贴图目录中，查找并切换到已经存在的同名 PNG、TGA、JPG 或 JPEG 文件，用于批量切换贴图。

该功能不会转换图像文件格式。共享图像、未保存图像和打包图像不会被修改。

### 便捷功能

功能注释：

- `复制着色器参数到选中项`：复制最后选中的源对象（高亮活动对象）的着色器参数，并应用到其他选中项。仅支持复制未连接且名称一致的输入值。
- `为选中项的材质查重与合并`：安全处理插件生成且尚未修改的重复材质。
- `为选中项恢复导入材质`：根据导入记录恢复导入时的材质和贴图关联。
- `独显选中项`：在当前 3D 视图中临时独立显示选中项，在独显期间可正常进行移动、编辑等操作，再次点击按键可恢复点击前的显示状态。

### PhotoshopToSpine 静态 JSON

该功能只作为有限支持，并非 PhotoshopToSpine 插件的替代项。

该功能可以导入由 PhotoshopToSpine 导出的静态碎图与 JSON。导出功能不会导出贴图，只会将当前 Blender 构图的位置信息记录在兼容 JSON 中并导出。

非常感谢 PhotoshopToSpine 插件的作者 EsotericSoftware，您的插件帮助我在早期的 2D 角色制作中节省了大量时间。

### Spine2D Region Attachment 导入

该功能只作为有限支持，不支持与 Spine 2D 软件本身进行关联。

该功能只能用于导入 Spine JSON 中的静态 Region Attachment，并按照 Setup Pose 创建矩形面片；不支持导入 Spine 动画、Mesh Attachment、约束系统或可动画的 Blender 骨架。

## 更多边界

1. 贴图互通以 RGB 8 位和 sRGB 显示工作流为主要目标，不适合作为 CMYK、16 或 32 位图像或严格色彩管理母版的无损往返方案。

2. JPG 和 JPEG 作为支持格式，但不支持透明通道，并且反复保存存在有损压缩。对 sprite、角色和 billboard，优先推荐 PNG 或 TGA 格式。

3. 有效的 2D 面片应当满足：

- 所有顶点位于统一二维平面，至少形成一个有效面区域，所有顶点属于同一连通区域；
- 外围只有一个闭环；外围轮廓必须是项目平面中的轴对齐矩形；外围边不得斜切或弯曲；
- 具有有效的活动 UV 层，满足连续矩形 UV 要求，且不存在局部拉伸或外围 UV 接缝；
- 可存在内部细分、三角化、矩形边上的额外共线顶点，但不允许出现内部孔洞、多个独立网格岛、一条边由三个或更多面共用的情况；
- 可存在约束、驱动器、动画和 NLA，但它们不会作为 Photoshop 往返数据。

4. 活跃项目、备份和恢复目录优先放在本机磁盘。云同步或网络目录可以使用，但同步冲突、延迟和非本地文件系统语义可能降低锁与恢复机制的可靠性。

5. 自动刷新应视为 `后台分片检查和稳定后的自动刷新`，并非零延迟同步。

自动刷新的轮询式机制为：

- 活跃状态最快间隔约 0.6 秒；
- 空闲间隔约 1.5 秒；
- 中大型项目放宽到约 2.5 或 4 秒；
- 单次扫描预算约 8 毫秒；
- 文件变化后等待约 0.35 秒确认稳定；
- 连续拓扑变化过多时会进入退避或暂停状态；
- 重新加载前进行检测与验证。

6. 部分单项按键与任务的边界如下表：

| 项目 | 代码上限或要求 | 边界说明及超出后处理方式 |
|---|---|---|
| PSD/PSB 导入单元数 | 最多 2048 项 | 包括最终导入计划中的贴图项 |
| PSD/PSB 文档宽高 | 每边最多 300,000 px | 插件安全检查上限 |
| 单张导出贴图宽高 | 每边最多 300,000 px | 实际上限通常较理论更低 |
| 归一化画布宽高 | 每边最多 300,000 px | Blender 直接建项目同样检查 |
| PSD 导出贴图总像素 | 最多 250,000,000 px | 所有输出贴图累计 |
| 透明扩边 | 0–8192 px | UI 和 JSX 双端限制 |
| 自动选择 PSB | 画布任一边超过 30,000 px | 直接创建项目时自动使用 PSB |
| 通用导入 JSON | 最大 64 MiB | 超出时阻断 |
| 取消确认等待 | 60 秒 | 不会强制终止 Photoshop |
| 结果读取重试 | 最多 5 次 | 另有约 5 秒重试窗口 |
| 自动刷新每次扫描 | 最多 32 个文件 | 单次时间预算约 8 ms |

| 自动刷新失败尝试 | 最多 5 次 | 延迟约为 1、2、5、10 秒 |
