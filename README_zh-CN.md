# Brandy Texture Link 2D —— 中文主页

[用户指南](docs/用户指南.md) · [技术支持](docs/技术支持.md) · [维护信息](docs/维护信息.md) · [更新日志](docs/更新日志.md) · [README](README.md)

**本 Blender 插件专为处理 2D 贴图设计，可调用 Photoshop 批量编辑贴图，之后在 Blender 中自动刷新显示。**

本插件支持使用 **Blender 集合** 或 **PSD 文档** 创建 **项目包**，从而建立 Blender 与 Photoshop 的关联，完成在 Photoshop 中复原 Blender 的贴图排列，或是在 Blender 中导入 PSD 文档的图层排列，并支持后续的编辑与刷新。

这对于 2D 游戏或动画管线来说，能够有效降低跨软件的贴图编辑难度与关联成本。

项目包作为关联桥梁，专门针对 `项目备份与恢复`、`安全撤销`、`多项目切换`、`项目副本迁移` 等防护性内容进行了设计，并完成了 7 * 5 个版本的矩阵测试（包含 Blender 5.2.0 LTS）。

`快速入门` 可直接阅读下文，`深度使用与使用须知` 可观看下方的 `视频教程` 或查看 [用户指南](docs/用户指南.md)，`测试详情` 可查看 [维护信息](docs/维护信息.md)。

插件支持中英双语，您可通过 **设置与报告** 分栏中的 **插件界面语言** 修改默认语言，修改后需要重新加载插件或重新启动 Blender。

## 快速入门

请先完成以下基础的插件安装与配置：

1. 在 Blender 中打开 **编辑** > **偏好设置** > **获取扩展** > 右上角菜单的 **从磁盘安装**，选择完整的 Brandy Texture Link 2D.zip 插件包。请不要解压 ZIP 文件。

2. 确保您在 **偏好设置** > **插件** 中启用了 Brandy Texture Link 2D。

3. 回到 3D 视图中按 `N` 键打开侧边栏，之后展开 **Brandy** 标签，在 **Photoshop 路径** 中选择 Photoshop 安装路径里的 `Photoshop.exe`。

### 从 Blender 集合建立关联

1. 在 **项目包路径** 中选择一个本地空文件夹，保持 **贴图来源** 为 **Blender 集合**。

2. 将您需要编辑的所有平面矩形 Mesh 对象（后文简称为 `2D 面片`）放入一个 Blender 集合，并在 **项目集合** 中选择该集合，之后点击 **创建项目**。

3. 插件会复制该集合中所有 `2D 面片` 的源贴图，粘贴到项目包中，并创建一个新的 PSD 文档，在 Photoshop 中复原 Blender 里的贴图排列。您创建项目前的源贴图不会被修改。

### 从 PSD 文档建立关联

1. 在 **项目包路径** 中选择一个本地空文件夹，将 **贴图来源** 切换至 **Photoshop 文档**。

2. 在 **PSD 文档** 中选择您要导入的 PSD 文档，在下方的导入参数中设置 **透明像素边距**、**使用 Alpha**、**面片 Z 轴间距** 等选项，之后点击 **创建项目**。

3. 插件会在 Blender 中，为每个成功导入的图层或资产创建一张 `2D 面片`，并将图层内容作为贴图接入材质。插件会按照 PSD 文档中的图层排列，处理 `2D 面片` 之间的前后遮挡顺序。

## 编辑与刷新

无论您使用哪一种方式建立关联，当 **项目包** 创建完成之后，您的 Photoshop 都会被启动。

同时，插件也会弹出下方的编辑面板，包含 **编辑单一贴图** 和 **应用待合并图层** 等按键，用于完成 `单图编辑模式` 和 `多图编辑模式` 两种主要编辑模式。

此时打开的 PSD 文档中，会存在 **BTL2 关联图层**、**BTL2 待合并图层**、**BTL2 已合并图层** 三个图层组。请勿删除这三个图层组。

在 **BTL2 关联图层** 图层组中，存放着所有与 `2D 面片` 名称对应的智能对象，它们的对应贴图、排列关系和 Alpha 信息都会在创建项目时被记录。

而 **BTL2 待合并图层** 和 **BTL2 已合并图层** 则是 `多图编辑模式` 的核心依赖。

### 单图编辑模式

您可直接在 Blender 中选中某个 `2D 面片`，点击插件的 **编辑单一贴图**，即可打开对应的贴图文件进行编辑。

当 **自动刷新** 处于激活状态时（按键亮起），您在 Photoshop 中的 `保存（Ctrl+S）` 操作会自动触发 Blender 中的刷新显示。自动刷新机制并非实时同步，在 `保存（Ctrl+S）` 操作后可能存在数秒延迟，延迟受项目大小及硬件情况影响。

您也可以关闭 **自动刷新**，通过 **刷新贴图** 进行手动刷新。

在 `单图编辑模式` 中，您需要执行编辑和保存的对象为 `单一贴图文件` 或总 PSD 文档中的 `单一智能对象图层`，仅对总 PSD 文档进行保存无法触发自动刷新。

使用 **编辑单一贴图** 进行编辑并保存后，在创建项目时被记录的 Alpha 信息变更为编辑后的 Alpha。这能够为擦除已有像素后的贴图提供可靠的 Alpha 信息，并直接影响后续的 **允许写入透明区域** 和 **允许分配至透明区域**。

### 多图编辑模式

该模式以 **应用待合并图层** 与 **分配待合并图层** 两个按键为核心，满足常见重绘管线中的各类需求。

1. **应用待合并图层**

例如：需要对 `Leg_Thigh` 、`Leg_Shin` 、`Leg_Foot` 三张贴图进行绘制。

此时可在总 PSD 文档中新建三个图层进行绘制，之后将三个新图层分别改名为 `Leg_Thigh` 、`Leg_Shin` 、`Leg_Foot`，一起放入 **BTL2 待合并图层** 图层组中，并对总 PSD 文档进行保存。

点击 **应用待合并图层**，插件会自动将三个新图层，按名称合并至对应的 `Leg_Thigh` 、`Leg_Shin` 、`Leg_Foot` 三张贴图中，并自动刷新显示。

此处仅以三张贴图举例，更多图层均可按此逻辑进行操作。

在未勾选 **允许写入透明区域** 时，插件会按当前记录的 Alpha 信息，自动裁切掉进入透明区域内的新增像素，确保原有像素边缘不会被扩展。

在勾选 **允许写入透明区域** 时，插件则允许新增像素写入透明区域，只会自动裁切掉超出原有画布大小的内容。

2. **分配待合并图层**

该按键的使用方式与 **应用待合并图层** 类似，是否勾选 **允许分配至透明区域** 的影响也与 **允许写入透明区域** 类似，相似内容不再赘述。

区别在于 **分配待合并图层** 会按照图层的遮挡顺序，对多个图层的重叠区域进行自动分配，确保在上层的贴图获得新增像素后，被遮挡的下层贴图不会获得相同像素。

例如：需要绘制一条横跨 `Leg_Thigh` 、`Leg_Shin` 、`Leg_Foot` 三张贴图的花纹，但三张贴图的关节部位均因“补肉”或“溢出”存在遮挡，而您不希望新增像素落入被遮挡的区域。

此时可新建一个图层绘制完整花纹，完成后对该图层执行两次 `复制并创建新图层（Ctrl+J）` 操作，得到三个相同内容的图层。将三个新图层分别改名为 `Leg_Thigh` 、`Leg_Shin` 、`Leg_Foot`，一起放入 **BTL2 待合并图层** 图层组中，并对总 PSD 文档进行保存。

点击 **分配待合并图层** 后，大腿与膝盖处的花纹会被分配至位于上层的 `Leg_Thigh` 贴图，而下层的 `Leg_Shin` 贴图不会再次获得膝盖处的花纹，只会获得未被遮挡的小腿处的花纹。

最终，整条花纹会被完整分配至 `Leg_Thigh` 、`Leg_Shin` 、`Leg_Foot` 三张贴图，不会产生断层，也不会因新增像素叠加而产生不可控的视觉变化，这对于半透明像素的处理尤为重要。

3. **对单图层分配**

该选项仅对 **分配待合并图层** 生效，效果类似智能分配。

勾选后，仅需在 **BTL2 待合并图层** 中放入一个新图层，插件会自动将检测到的所有新增像素，按照 **分配待合并图层** 的逻辑，自动分配至下方所有被覆盖的贴图中。

如果放入多个图层，插件会先对 **BTL2 待合并图层** 中的所有新图层进行合并，再执行分配。

该选项很便捷，但耗时较长，也相对不可控，建议小范围使用。

4. **撤销上次应用** 与 **撤销上次分配**

在每次执行完 **应用待合并图层** 或 **分配待合并图层** 后，插件会在两个按键下方分别弹出 **撤销上次应用** 或 **撤销上次分配**。

点击撤销后，插件会复原上次操作影响的贴图，并将被应用或分配的新图层放回 **BTL2 待合并图层** 中。

该撤销仅对前一次的操作生效，且应用和分配操作共享同一次撤销机会，即在执行 **应用待合并图层** 后再执行 **分配待合并图层**，上一次的 **应用待合并图层** 便不再支持撤销。

未生效的操作，如对空图层执行的应用和分配，不会消耗该撤销机会。

## 支持信息

### 支持环境

- Windows x64
- Blender 4.2.0 - 5.2.0（含 5.2.0）
- Adobe Photoshop 桌面版 CC2017 - 2026（含 2026）

### 支持项目类型

- 格式为 PNG、JPG、JPEG、TGA 的贴图。
- PSD 中的平面角色或分层内容。
- Blender 中的矩形面片模型。
- 2D 游戏与动画管线，2D 角色与场景。
