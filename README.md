# Brandy Texture Link 2D

[Quick Start](docs/QuickStart.md) · [User Guide](docs/UserGuide.md) · [Support](docs/Support.md) · [Maintenance](docs/Maintenance.md) · [Change Log](docs/ChangeLog.md) · [中文主页](README_zh-CN.md)

**Brandy Texture Link 2D is a Blender add-on built for 2D game and animation workflows. It lets you edit textures used by flat 2D mesh assets and keeps Blender and Photoshop linked throughout the project.**

## Core Features

## Support Information

### Supported Environment

* Windows x64
* Blender 4.2.0 - 5.2.0, including 5.2.0
* Adobe Photoshop desktop CC2017 - 2026, including 2026

### Supported Project Types

* 2D game and animation workflows, including 2D characters and scenes.
* Textures in PNG, JPG, JPEG, and TGA formats.
* 2D characters or layered artwork in PSD documents.
* Rectangular mesh sprites in Blender.

## Additional Notes

The add-on includes Chinese and English interfaces. Change the default language with **Interface Language** under **Settings & Reports**, then reload the add-on or restart Blender.

It also includes a small set of import/export tools and everyday utilities, plus safety and recovery controls that appear when needed. See the [User Guide](docs/UserGuide.md) for details.

The project folder acts as the bridge for the Blender–Photoshop link. The workflow includes project backup and recovery, safe undo, multi-project switching, and support for independent project copies. The add-on has also been tested across a 7 * 5 version matrix including Blender 5.2.0 LTS. See [Maintenance](docs/Maintenance.md) for details.

If you have questions or want to report an issue, see [Support](docs/Support.md) or contact `brandyspe2026@gmail.com`. I will reply as soon as I can after receiving your email.

Brandy Texture Link 2D was previously named Brandy 2D Link. Version `1.1.0` is the first public release under the new name.

The rename came with a major overhaul of the core workflow, including PSD document import, Split Merge Layers, transparent-area controls, Alpha reference updates, and a streamlined UI designed around practical day-to-day use.

Users who received an older version have already been provided with the new release.

To keep the GIF demos concise, waiting periods have been shortened. Actual processing time varies with project size and hardware performance. The character shown in the demos comes from a real Blender project with 49 2D sprites, bones, and animation.
